Liquid Glass - Brand Style Guide
1. Core Philosophy
The Liquid Glass brand is built on a foundation of clean, modern, and intelligent design. Our goal is to create digital experiences that are not only beautiful but also intuitive and calming.
Keywords: Simple, Fluent, Modern, Intelligent, Elegant, Calm, Focused.
Feeling: Users should feel a sense of effortless control and clarity. The interface should feel like a natural extension of their thoughts, beautiful to look at but disappearing into the background as they work.

3. Typography
We use a single font family, Inter, for its exceptional readability and clean, neutral aesthetic.
Font Family: Inter, sans-serif
Headings (<h1>, <h2>):
Weight: Bold (700)
Color: #FFFFFF (Pure White)
Sub-Headings (<h3>, <h4>):
Weight: Semi-Bold (600)
Color: #E0E0E0 (Off-White)
Body & Paragraphs (<p>):
Weight: Regular (400)
Color: #E0E0E0 (Off-White)
4. Signature Components
These are the core building blocks of the Liquid Glass UI.
The .glass-panel
This is our signature container for all primary content.
Background: rgba(30, 30, 30, 0.6)
Backdrop Filter: blur(12px)
Border: 1px solid rgba(255, 255, 255, 0.1)
Border Radius: 1rem (16px)
Box Shadow: 0 8px 32px rgba(0, 0, 0, 0.2)
The .brand-button
Our primary call-to-action button.
Background: #00BCD4 (Vibrant Cyan)
Text Color: #000 (Dark Cyan)
Font Weight: 600
Border Radius: 0.75rem (12px)
Hover Effect: Subtle upward transform and increased shadow.
The .brand-input
Standard for all text entry fields.
Background: rgba(0, 0, 0, 0.2)
Border: 1px solid rgba(255, 255, 255, 0.1)
Border Radius: 0.75rem (12px)
Focus State: Border color changes to #00BCD4 (Vibrant Cyan).
5. Recommended Gemini/AI Prompt
Use this prompt when brainstorming or commissioning a new application to ensure it aligns perfectly with the Liquid Glass brand identity.
Prompt: "Design a concept for a new simple application for [describe the app's purpose, e.g., 'taking quick notes,' 'tracking habits,' 'a simple calculator'].
The design must strictly adhere to the 'Liquid Glass' brand style guide.
Key constraints:
The entire UI must be built around a central 'glass-panel' component.
The background must be a dark, animated gradient.
The color palette is fixed: a deep dark theme with a vibrant cyan (#00BCD4) as the only interactive accent color.
The font must be 'Inter.'
The overall feeling must be simple, fluent, and modern. Prioritize a clean layout and an intuitive user experience over feature density."
